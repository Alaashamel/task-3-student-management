# Task 3 - Student Management System

A simple Student Management System built with HTML and JavaScript.

## Features

- Add students with Name, Age, and Grade
- Show all students in console
- Search students by Name or Grade
- Delete students
- Login system (Bonus)

## Project Structure

```
task-3-student-management/
├── index.html          # Main HTML file
├── src/
│   ├── css/
│   │   └── styles.css  # Styles
│   └── js/
│       └── app.js      # Main JavaScript
└── README.md
```

## Usage

1. Open `index.html` in a web browser
2. Fill in student details (Name, Age, Grade)
3. Use buttons to manage students

## JavaScript Concepts Used

- Function Declaration, Expression, and Self-Invoking Functions
- Global and Local Scope
- Loops (for, while, do...while)
- Browser Objects (console.log, alert, document.write)
- Switch statements
